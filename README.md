# 🎬 AI Video Studio

Бесплатный инструмент с открытым исходным кодом. Заменяет в видео **лица** нескольких персонажей и их **голоса**
на лица и голоса других людей, которые дали на это согласие. Управляется через веб-интерфейс с iPhone и работает на бесплатном GPU Kaggle.

* 👤 Автоматически находит всех персонажей в видео. Каждому можно назначить своё лицо.
  Используются HyperSwap 256, XSeg-маски окклюзии и GFPGAN, есть трекинг и защита от мерцания.
* 🗣 Разделяет голос и фоновую музыку (BS-RoFormer) и определяет, кто когда говорит.
  Заменяет голос через **Seed-VC**: сохраняются слова, эмоции, интонация, паузы и темп, русский язык поддерживается.
* 👄 Синхронизация губ сохраняется сама: преобразование голоса не меняет тайминг речи (подробнее в `docs/ARCHITECTURE.md`).
* 🎞 На выходе MP4 до 1080p с исходной частотой кадров, без водяных знаков сторонних сервисов,
  с обязательной пометкой «Создано с помощью ИИ» в кадре и в метаданных.
* 🧪 Можно сделать тест 5 секунд до полной обработки и перегенерировать отдельный фрагмент.
  Есть прогресс-бар, понятные сообщения об ошибках и кнопка удаления всех данных.

**Как запустить:** см. [docs/ИНСТРУКЦИЯ.md](docs/ИНСТРУКЦИЯ.md) — пошагово, для iPhone.
**Как устроено и почему:** [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```
kaggle/ai_video_studio.ipynb   ноутбук для Kaggle (3 ячейки)
install.py                     установка зависимостей и моделей
studio/app.py                  веб-интерфейс (Gradio)
studio/pipeline.py             проект, фоновые задачи, кэш фрагментов
studio/faces.py                детекция, трекинг, кластеризация, замена лиц
studio/audio.py                разделение, диаризация, подготовка образцов, сведение
studio/vc_worker.py            запуск Seed-VC в отдельном процессе
studio/media.py                ffmpeg: нормализация, чтение/запись кадров, пометка ИИ
tests/smoke_test.py            сквозная проверка на синтетических данных
```

Только для законного использования с согласия всех изображённых и озвучиваемых людей.
У ряда моделей лицензия только для некоммерческого использования (см. таблицу лицензий в ARCHITECTURE.md).
