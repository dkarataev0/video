# Пошаговая инструкция (для iPhone, без навыков программирования)

## ⚡ Быстрый старт — одна ячейка

1. kaggle.com → войти → подтвердить телефон (аватар → Settings → Phone verification).
2. В Safari: «аА» → «Запрос веб-сайта для ПК». На Kaggle: **Create → New Notebook**.
3. Справа **Settings**: **Accelerator → GPU T4 x2**, **Internet → On**.
4. Удалите пустую ячейку, нажмите **+ Code** и вставьте эту строку целиком:

```
!git clone -q --depth 1 -b claude/face-swap-voice-clone-yijuew https://github.com/dkarataev0/video.git /kaggle/working/video 2>/dev/null || git -C /kaggle/working/video pull -q; python /kaggle/working/video/install.py && cd /kaggle/working/video && python -m studio.app --share
```

5. Нажмите ▶ и подождите 10–15 минут. Внизу появится блок **«ГОТОВО!»** со ссылкой, логином и паролем.
   Откройте ссылку в новой вкладке Safari. Вкладку Kaggle не закрывайте.
6. Дальше работайте по «Части 4» ниже.

---

Время на первый запуск — около 20 минут. Дальше — 10 минут на запуск плюс время обработки.
Ориентир обработки на бесплатном GPU T4: 1 минута видео с двумя лицами — примерно 5–15 минут.
Это оценка, а не замер: проект проверялся только на CPU, а на GPU не тестировался.

> ⚖️ **Важно.** Используйте только лица и голоса людей, которые дали согласие. Это касается и людей в исходном видео.
> Программа ставит на видео заметную пометку «Создано с помощью ИИ» и прописывает её в метаданные файла.
> Не удаляйте пометку и не выдавайте видео за настоящее.

---

## Часть 1. Подготовка (один раз)

1. **Аккаунт Kaggle.** Откройте в Safari kaggle.com и зарегистрируйтесь (можно через Google).
2. **Подтверждение телефона.** Нажмите на аватар → **Settings** → **Phone verification** → введите номер и код из SMS.
   Без этого Kaggle не даст включить GPU и Интернет.
3. **Доступ к программе.** Программа лежит в репозитории GitHub `dkarataev0/video`.
   * Если репозиторий **публичный**, ничего делать не нужно.
   * Если **приватный**, создайте на GitHub токен (Settings → Developer settings → Fine-grained token, право *Contents: Read* на этот репозиторий).
     Затем в Kaggle, в ноутбуке: **Add-ons → Secrets → Add secret**, имя `GITHUB_TOKEN`, значение — токен.
4. **Ноутбук.** На Kaggle: **Create → New Notebook**. В меню **File → Import Notebook** загрузите файл
   `kaggle/ai_video_studio.ipynb` из репозитория. Скачать его на iPhone можно так: откройте файл на github.com → кнопка «…» → *Download*.
5. **Настройки ноутбука.** Удобнее всего в Safari переключить режим «Версия для ПК» (значок «аА» в адресной строке).
   Справа на панели **Settings** выберите:
   * **Accelerator → GPU T4 x2** (или «GPU T4»);
   * **Internet → On**.

## Часть 2. Подготовьте файлы на iPhone

* **Видео** — из «Фото» или «Файлов», MP4 или MOV. Подходит любое видео с iPhone, включая HDR и 4K.
  Программа сама уменьшит его до 1080p и сохранит исходную частоту кадров.
* **Фото новых лиц** — для каждого человека 3–10 фото: лицо крупно, хороший свет, без тёмных очков, лучше с разных ракурсов.
  Чем больше разнообразных фото, тем стабильнее результат.
* **Образцы голосов** — для каждого нового голоса 10–30 секунд чистой речи. Запись из «Диктофона» (.m4a) подходит.
  Говорить лучше естественно, в тихом помещении. Музыку и шум программа по возможности уберёт сама.

## Часть 3. Запуск (каждый раз)

1. Откройте ноутбук на Kaggle и проверьте, что вверху справа включён GPU.
2. Нажмите ▶ у ячейки **«Шаг 1»** и дождитесь сообщения «✅ Готово».
3. Нажмите ▶ у ячейки **«Шаг 2»** и подождите 5–10 минут, пока не появится «✅ Установка завершена».
   В строке `onnxruntime` должно быть написано `CUDAExecutionProvider`. Если его нет, лица будут обрабатываться в разы медленнее.
4. Нажмите ▶ у ячейки **«Шаг 3»**. Через 1–2 минуты появятся **ЛОГИН**, **ПАРОЛЬ** и строка
   `Running on public URL: https://….gradio.live`.
5. Скопируйте ссылку и откройте её **в новой вкладке** Safari. Введите логин и пароль.
   **Вкладку Kaggle не закрывайте**, ячейка «Шаг 3» должна продолжать работать.

## Часть 4. Работа в интерфейсе

1. Поставьте **галочку согласия** вверху страницы.
2. **Вкладка «1. Видео»** — загрузите видео. Анализ начнётся сам: прогресс-бар покажет поиск лиц, отделение голосов от музыки и определение говорящих.
   Телефон можно заблокировать: работа идёт на сервере, а страница обновится, когда вы вернётесь.
3. **Вкладка «2. Лица»** — появятся карточки найденных персонажей. Для тех, кого нужно заменить, нажмите «Фото нового лица» и выберите фото.
   * Если один человек попал в две карточки, загрузите одни и те же фото в обе.
   * Если разные люди слились в одну карточку, откройте «Один человек разбит…» и уменьшите порог.
4. **Вкладка «3. Голоса»** — прослушайте найденные голоса и загрузите образец нового голоса для нужных.
   Если программа ошиблась, откройте «Исправить, кто когда говорит» и укажите число говорящих или поправьте таблицу.
5. **Вкладка «4. Настройки»** — по умолчанию выставлено на максимальное качество. Менять ничего не обязательно.
6. **Вкладка «5. Тест и результат»:**
   * укажите секунду, где есть лица и речь, и нажмите **«Тест 5 секунд»** — посмотрите, нравится ли результат;
   * нажмите **«Полная обработка»**. Когда закончится, появятся видео и кнопка **«Скачать MP4»**.
     В Safari: нажмите на файл → «Поделиться» → «Сохранить видео»;
   * если в каком-то месте брак, откройте «Перегенерировать фрагмент», укажите секунды и (по желанию) другие настройки или фото,
     затем нажмите «Перегенерировать». Пересчитается только этот кусок.
7. **Вкладка «🔒 Данные»** — после скачивания удалите все данные. Затем в Kaggle остановите сессию: кнопка ⏻ / *Stop session*.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| «GPU не найден» | В Kaggle: Settings → Accelerator → GPU. Затем Run → Restart & clear, и снова шаги 1–3 |
| Не скачивается программа или модели | Settings → Internet → On (нужен подтверждённый телефон) |
| Ссылка gradio.live не открывается | Проверьте, что ячейка «Шаг 3» ещё работает. Если остановилась, запустите её снова: появится новая ссылка и новый пароль |
| «На фотографиях не найдено лицо» | Загрузите фото, где лицо крупнее и видно полностью |
| Лицо дрожит или мерцает | Настройки: «Подавление мерцания» 0.7–0.8, «Улучшение лица» 20–30 % |
| Лицо мало похоже на нужного человека | Добавьте больше фото. «Сила сходства» 0.6–0.7. Попробуйте модель `hyperswap_1b_256` или `1c` |
| Голос звучит не тем тембром | Образец длиннее и чище (20–30 с), включите «Очищать образцы» |
| Голос «поёт» или неестественная высота | Снимите галочку «Точно сохранять интонацию» или поправьте «Сдвиг высоты» |
| Закончилась квота GPU | Квота Kaggle обновляется раз в неделю. Остаток виден в профиле → Settings / Quotas |
| Сессия прервалась | Обработанные данные стираются вместе с сессией. Запустите шаги 1–3 заново и повторите. Скачивайте результат сразу |

Подробности о моделях и ограничениях — в `docs/ARCHITECTURE.md`.
